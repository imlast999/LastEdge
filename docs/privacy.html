Privacy Policy for LastEdge

Application: LastEdge (com.lastedge.app) · Effective Date: November 2026

1. Privacy Commitment

At LastEdge, data privacy, user confidentiality, and operational sovereignty are foundational principles. LastEdge is a client application designed for real-time quantitative monitoring and algorithmic trading telemetry interfaced with MetaTrader 5 (MT5).

We do not collect, sell, monetize, rent, or share any personal, financial, or trading activity data with third parties.

2. Data Storage & Local Client Processing

All sensitive configuration details and credentials necessary for operating the application are stored and processed exclusively locally on the user's physical device:

  • Server Connection Endpoints (URL/IP) & Ports: Stored strictly in the device's hardware-backed encrypted keystore (SecureStore / Android KeyStore).
  • API Keys & Authentication Tokens: Kept locally on device and transmitted exclusively via direct, encrypted HTTPS/WSS channels between the client and the user's private, self-hosted LastEdge server.
  • Historical Trades & Execution Telemetry: Queried on demand directly from the user's private server and temporarily cached in memory to accelerate high-definition charting renders.

3. Device Permissions & Technical Justification

The application requests only the minimum set of permissions strictly necessary to execute its technical functions:

  • Internet Access (INTERNET / ACCESS_NETWORK_STATE): Required to establish encrypted REST and WebSocket connections with the user's private LastEdge Trading Engine and query account balance, equity, and open positions.
  • Push Notifications (POST_NOTIFICATIONS): Required to deliver real-time actionable notifications regarding trade executions, Take Profit (TP), Stop Loss (SL) triggers, and Risk Engine circuit breakers.
  • Vibration (VIBRATE): Required to provide haptic feedback when priority execution alerts and risk warnings are received.

The application DOES NOT request or access device camera, contacts, GPS location, microphone, or external shared storage.

4. Zero Third-Party Advertising & Tracking

LastEdge contains zero third-party advertising SDKs, behavioral tracking frameworks, or commercial analytics pixels (no Google AdMob, no Meta Facebook Pixel, no external broker trackers). The application operates with a clean, privacy-first architecture focused on data sovereignty.

5. Financial Software Disclaimer

LastEdge is technical software for quantitative analysis and algorithmic execution telemetry.

  • LastEdge is NOT a broker, dealer, investment advisor, or regulated banking institution.
  • LastEdge DOES NOT hold client deposits, custody funds, or process fiat or cryptocurrency payment transactions.
  • LastEdge DOES NOT provide personalized investment advice or solicitation of financial products.
  • Trading foreign exchange, commodities, and digital assets carries substantial financial risk. Past quantitative performance is not indicative of future returns.

6. Data Sovereignty & Complete Erasure

The user maintains full sovereignty over all stored data at all times. To delete all cached data, connection settings, and credentials, the user can select "Reset Settings" within the in-app Settings modal or simply uninstall the application.

For technical inquiries, bug disclosures, or questions regarding this Privacy Policy, contact the development team through our official GitHub repository:

1. Compromiso de Privacidad

En LastEdge nos tomamos la privacidad y la soberanía de los datos con el máximo rigor institucional. LastEdge es una aplicación cliente de monitorización cuantitativa y control de trading algorítmico conectada a MetaTrader 5 (MT5).

No recopilamos, no vendemos, no monetizamos ni compartimos ningún dato personal, financiero ni de operativa con terceros.

2. Datos Almacenados y Tratamiento Local

Toda la información sensible necesaria para operar con la aplicación se almacena y procesa exclusivamente de forma local en el dispositivo del usuario:

  • Direcciones de conexión (URL/IP) y puertos: Se almacenan en el almacenamiento cifrado del dispositivo (SecureStore / KeyStore de Android).
  • Claves de API y credenciales de acceso: Se guardan localmente y se transmiten únicamente de manera directa y cifrada entre el cliente móvil y el servidor privado autohospedado del usuario.
  • Historial de trades y telemetría: Se descargan bajo demanda desde el servidor del usuario y se conservan en memoria caché local para agilizar la visualización gráfica.

3. Permisos Requeridos y Finalidad

La aplicación solicita únicamente los permisos estrictamente indispensables para su funcionalidad técnica:

  • Acceso a Internet (INTERNET / ACCESS_NETWORK_STATE): Requerido para comunicar con la API REST y WebSockets del servidor LastEdge del usuario y consultar el balance, equity y posiciones de MT5.
  • Notificaciones (POST_NOTIFICATIONS): Requerido para alertar en tiempo real sobre aperturas de trades, cierres por Take Profit (TP), Stop Loss (SL) y activaciones del Circuit Breaker de riesgo.
  • Vibración (VIBRATE): Requerido para proveer retroalimentación háptica en la recepción de alertas de trading prioritarias.

La aplicación NO solicita acceso a cámara, contactos, ubicación por GPS, micrófono ni almacenamiento de archivos externos.

LastEdge no contiene librerías ni SDKs de publicidad invasiva, rastreo conductual o telemetría publicitaria (sin Google AdMob, sin Meta Facebook Pixel, sin brokers comerciales integrados). La aplicación opera bajo una arquitectura limpia y orientada a la soberanía de datos del usuario.
